# 杭州知识库首批语料包

整理日期：2026-09-14

本目录用于管理员上传前的本地审查，不是运行时知识库。`source-pdfs/` 保存官方原始 PDF，`documents/` 保存依据官方网页制作的事实摘要，`manifest.csv` 提供管理页面所需元数据和处理建议。

## 筛选原则

- 仅使用政府、文旅部门、景区场馆、公共交通运营机构的官方网站。
- 优先保留游客会直接询问的开放时间、预约、入场、交通、票务与安全规则。
- 排除活动新闻、短期施工、临时线路调整和文旅产业规划等低复用内容。
- 网页摘要不冒充原始公告，正文必须保留来源 URL、源发布日期或快照日期。
- 开放时间、票价、预约和班次均可能变化；涉及实际出行时必须再次查看来源页面。

- 主题拆分 PDF：2 份，均保留官方原页，暂缓上传等待动态事实复核。

- 不要同时上传内容高度重叠的机场到达 PDF 和网页摘要，避免相似切片互相竞争。

## 上传流程

1. 按 `manifest.csv` 核对 `decision=UPLOAD` 的文件和元数据。
2. 使用 ADMIN 账号进入 `/admin/knowledge`。
3. 逐份选择文件，并复制标题、城市、发布机构、来源地址、发布日期和文档类型。
4. 上传后确认状态为 `ACTIVE`，抽查切片没有导航菜单、乱码或明显过期信息。
5. 全部完成后记录实际文档 ID；仅在索引恢复或整体校验时使用“重建正式索引”。
