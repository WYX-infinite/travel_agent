## 面试时必须说明的边界

- “100%”只适用于固定离线 fixture 的特定指标，不是模型准确率。
- 4/15 引用覆盖只表示结构化证据存在，不证明引用语义充分支持活动。
- 106/112 规则通过率包含 warning；任务 `COMPLETED` 不等于零 warning。
- 真实冒烟只是一次两个固定场景的小样本；不得换算为成功率。两场景仍有费用证据、费用完整性、开放时间和路线未验证 warning。
- 受控路线失败来自不可达 loopback；只能说验证了安全错误映射，不能说高德真实发生故障。
- Redis 本次不可达且缓存命中为 0；只能说故障回源完成，不能说真实缓存命中已验证。
- 40 条用例不是随机样本，没有置信区间，不能外推真实用户规模。
- 没有经过压力、灾备、漏洞修复和多实例一致性验证，不能称生产级系统。
