# 多约束旅行规划 Agent 每日执行表

日期：2026-09-02  
目标：2026-10-13 前完成六个阶段的主范围，2026-10-14 至 2026-10-18 用于缓冲、演示和求职材料。  
投入：每天 2 小时，工作日与周末相同。  
分工：任务 1～18 由 Codex 主导实施，用户负责必要的个人账号操作、数据来源审核和阶段验收。

## 一、每日执行规则

每个两小时窗口原则上按以下方式使用：

1. 约 10 分钟：检查上次提交、未解决问题和当天依赖。
2. 约 80～90 分钟：按实施计划完成当天最小可交付改动。
3. 约 20～30 分钟：运行对应测试或构建，记录失败证据并修复能够当日解决的问题。
4. 约 10 分钟：提交已验证的改动，向用户说明完成内容、验证结果和次日目标。

某一天出现依赖下载、第三方接口、数据库结构或真实凭据阻塞时，优先完成模拟测试和不依赖真实服务的代码；阻塞项移入缓冲日。不得通过删除测试、放宽真实性规则或提交真实密钥赶进度。
